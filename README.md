# THMALL Meta Ads 성과 대시보드

`index.html`을 열면 바로 볼 수 있는 단일 HTML 대시보드입니다. 외부 리소스 의존 없이 완전히 자체 포함(self-contained)되어 있어 오프라인에서도, GitHub Pages에 그대로 올려도 동일하게 동작합니다.

## 포함 내용
- 요약 KPI (지출 · 구매 · 전환값 · ROAS)
- 월별 / 주별 / 일별 트렌드
- 캠페인별 · 애드셋별 성과 (ROAS 기준 색상 구분)
- 소재(광고)별 성과 — 성과 있는 소재 vs 없는 소재
- 연령 / 성별 / 기기 인구통계 분석
- 종합 인사이트

우측 상단 버튼으로 라이트/다크 모드 전환이 가능하고, 각 차트 아래 "데이터 테이블 보기"를 펼치면 원본 수치를 표로 확인할 수 있습니다.

## GitHub Pages로 배포하기
1. 이 폴더(`index.html`)를 저장소에 커밋합니다.
2. 저장소 Settings → Pages에서 배포 브랜치/폴더를 지정합니다.
3. 발급된 URL로 대시보드에 바로 접속할 수 있습니다.

## 데이터 기준
- 계정: THMALL (`act_885213872590921`)
- 기준일: 2026-08-25 / 최근 30일(2026-07-26~2026-08-24) 및 최대 이력(트렌드)
- "구매(공유항목)"은 Meta 카탈로그 협력광고의 `catalog_segment_actions:omni_purchase` 지표 기준입니다.
